# 6. Where the zeros enter: a prime-sum bound on windows (statements only)

*Written by Halley, 2026-11-22. Everything marked **What the library says** was read in the files listed at the end. Statements and definitions only; the one proof read in full is ten lines long. One Mathlib check was run with Lean and is reported where it is used. Nothing here has been checked by a mathematician.*

## In one paragraph

[Note 5](05-the-pivot.md) ended at `UpperTheory.Top.zeroFreeAll_of_topG`, whose input `TopG` concludes something about families ("connected"), not about zeros. Its ten-line proof hands everything to one theorem, `Formalism.HC.zeroFreeOn_of_tiedWin_cyc`. That theorem's hypotheses are where zeros finally appear, and they appear in a classical shape:
- **The prime sum.** A sum over the von Mangoldt function, Σ Λ(n)·(x/n − 1), minus its expected main term, plus the matching twisted sums for the characters of a level, is called `Gm`.
- **(A) The window bound.** On certain *windows* of x, the families built by the rest of the library force `Gm(x) ≤ x^(1/2 + O(ε))`.
- **(B) The Landau step.** If `Gm(x) ≤ x^θ` on windows [Y, Y^la] for arbitrarily large Y, then no L-function of the level vanishes to the right of θ.

With θ just above 1/2, (A) and (B) give the zero-free half-plane.

## What the library says

### The ten-line proof, read in full

`Development/AutomorphicArithmetic/CharacterBoxes/ZeroFreeAllOfTopG.lean`, lines 26-35:

```lean
theorem zeroFreeAll_of_topG {la : ℝ} (hla : 1 < la) (h : TopG) (hS : ∀ ψ : PChar, HostExW la (GChi ψ).req) : ZeroFreeAll := by
  have key : ZeroFreeOn fun _ => True :=
    zeroFreeOn_of_tiedWin_cyc (Fam := FamP) (core := fun Fm => Fm.toFamCore) (Tied := fun Fm => ChainTied Fm) hla
      (fun ψ _ => UpperTheory.Comparison₂.level_gm_le_on_family_scales _) (fun ψ _ => UpperTheory.Comparison₂.formB _) fun ψ _ => by
        obtain ⟨eD, eL, ε₁, h1, h2⟩ := h la (GChi ψ) hla (hS ψ) (hypV_of_cls ψ la)
        refine ⟨eD, eL, ε₁, h1, fun eps a b => ?_⟩
        obtain ⟨Fm, c, d⟩ := h2 eps a b
        exact ⟨Fm, eFamC_of_cls ψ la Fm c, c.1, d⟩
  exact key
```

**What it does with `TopG`, in two lines.** For each primitive ψ, it applies `TopG` at the scale `la` to the requirement `GChi ψ`. It feeds in ψ's host property (from `VWin`, note 5) and `hypV_of_cls`, and so gets `FamilyClassConnected` for ψ's family class. It then unpacks that conclusion into constants eD, eL, ε₁ and, for each small ε, a family `Fm`. It repackages them as the third hypothesis of `zeroFreeOn_of_tiedWin_cyc`, adding `eFamC_of_cls` and the first component of the class membership.

The unpacking pattern `⟨eD, eL, ε₁, h1, h2⟩` and then `⟨Fm, c, d⟩` matches the shape of `ChebyshevInequalityAtWindowScale` below. I have not read the definition of `FamilyClassConnected` itself.

### (a) `Formalism.HC.zeroFreeOn_of_tiedWin_cyc`

`Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/TopWin.lean`, line 90. The file was found by search, not by guess. It is a sibling of `ExplicitFormulaErrorOfHostConditions.lean` in the same folder.

```lean
theorem zeroFreeOn_of_tiedWin_cyc {Q : PChar → Prop} {la : ℝ} (hla : 1 < la)
    (h112 : ∀ ψ, Q ψ → ChebyshevInequalityOnWindows @core @Tied (Level.cyc ψ))
    (hB : ∀ ψ, Q ψ → (Level.cyc ψ).FormB)
    (h : ∀ ψ, Q ψ → ChebyshevInequalityAtWindowScale @core @Tied la (Level.cyc ψ)) : ZeroFreeOn Q
```

The section variables are a family type `Fam`, a map `core : Fam eps → FamCore eps`, and a relation `Tied` (line 20). On the path they are `FamP`, `Fm.toFamCore` and `ChainTied`.

**Hypotheses, one sentence each.** Q is `True` on the path, so "every ψ" below means every primitive ψ.
- `hla`: the window exponent la exceeds 1.
- `h112`: for every ψ, the Chebyshev-type window inequality holds for the level `Level.cyc ψ` (defined below).
- `hB`: for every ψ, the Landau step `FormB` holds for that level.
- `h`: for every ψ, at scale la there are families with the right windows that satisfy `Tied`.

**In words:** if, for every primitive ψ, the level generated by ψ has the window inequality, the Landau step, and families at the right scale, then no primitive L-function vanishes to the right of 1/2.

**The definitions it uses.** All are in `Formalism.HC`; lines are given per file.

- `Level.cyc ψ` (`ExplicitFormulaErrorOfHostConditions.lean`, line 121) is `Level.ofSub (Subgroup.zpowers ψ.χ)`. That is the "level" whose kept characters are the primitive characters attached to the powers of ψ. `Level.mem_cyc` (line 123) proves ψ is among them.
- `Level.Gm` (same file, line 38) is the quantity everything turns on:

  ```lean
  def Gm (y : ℝ) : ℝ := Formalism.Gz y + ∑ ψ ∈ Λ.Nt, Λ.wt ψ * (An.gChi ψ.χ y).re
  ```

  Here `Λ` is the level, `Nt` is its kept characters minus the trivial one (line 32), and `wt` is a weight, either 1 or (3·o + 1)⁻¹ where o is the level's order (line 36). The two pieces:
  - **`Formalism.Gz`** (`Formalism/StatementOC.lean`, lines 11-13):

    ```lean
    def Sz (x : ℝ) : ℝ := ∑ n ∈ Finset.Icc 1 ⌊x⌋₊, Λ n * (x / n - 1)
    def Gz (x : ℝ) : ℝ := Sz x - x * Real.log x + (1 + Real.eulerMascheroniConstant) * x
    ```

    Here `Λ n`, with `ArithmeticFunction` open, is Mathlib's von Mangoldt function. The release declares no notation of its own for `Λ` (a search found none). I checked with Lean, against Mathlib at the pinned commit, that under `open ArithmeticFunction` the symbol `Λ` is `ArithmeticFunction.vonMangoldt`, by definitional equality.
  - **`An.gChi χ y`** (`Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/Analytic.lean`, line 23). For χ ≠ 1 it is Σ_{n ≤ y} Λ(n)·χ(n)·max(y/n − 1, 0) + y·(L′(1, χ)/L(1, χ)). (Lines 11-24; L′(1, χ)/L(1, χ) is `logDerivativeAtOne`.)
- `ChebyshevInequalityOnWindows Λ` (`TopWin.lean`, lines 26-28): for all eD, eL and ε > 0, and every family `Fm` with `EFamC Λ (core Fm)` that satisfies `ChebyshevInequalityOnFamilyWindows … Fm eD eL`, there is x₁ such that for all x ≥ x₁ in the family's window set, `Λ.Gm x ≤ x^(1/2 + (eD + eL + 7)·ε)`.
  - The exponent sits in this definition's conclusion, at line 28.
  - The inner `ChebyshevInequalityOnFamilyWindows` (line 23) carries no exponent. It says only that there are constants K, cHH, eK, CL and x₀ such that `Tied Fm eD eL K cHH eK CL x` holds for every x ≥ x₀ in the window set.
- `Level.FormBAt la` (`Window.lean`, line 30):

  ```lean
  def FormBAt (la : ℝ) : Prop :=
    ∀ θ : ℝ, 0 < θ → θ < 1 → HasWindows {x | Λ.Gm x ≤ x ^ θ} la → Λ.ZeroFreeAbove θ
  ```

  `HasWindows S la` (line 7) means that for every y there is Y ≥ y with the whole interval [Y, Y^la] inside S. `Level.FormB` (line 33) is `FormBAt la` for every la > 1. The same file also defines `LandauWinAt` (line 24), the contrapositive-shaped statement: a zero to the right of θ forces, in every late window, some y with y^θ < Gm(y).
- `ChebyshevInequalityAtWindowScale la Λ` (`TopWin.lean`, line 30): there are eD, eL and ε₁ > 0 such that for each 0 < ε < ε₁ there is a family `Fm` with `EFamC Λ (core Fm)`, with windows at scale la, on which `Tied` holds.

## Interpretation (ours; check it)

- **The classical skeleton.** Up to the weights, `Gz(x)` is the first Riesz (Cesàro) mean of the prime-counting function ψ(x) = Σ_{n≤x} Λ(n), minus its main term. `gChi` is the same for a character, with the L′/L(1, χ) correction. This is our reading of the formulas; a reader should check the main-term constants.
  - `FormBAt` is a Landau-type theorem: a Dirichlet series built from these sums, with positivity coming from the weights, cannot have a zero to the right of θ if the sum stays below x^θ on long windows. The folder name `LandauTheorems` and the definition named `LandauWinAt` agree with that reading.
  - `ChebyshevInequalityOnWindows` with exponent 1/2 + O(ε) is a square-root bound on that sum, but only on windows, not for all x.
  - So the deep content has been reduced to: **find, for each ψ, arbitrarily long windows on which the twisted prime sums have square-root cancellation.** The "families" and their "ties" are the machinery that produces those windows.
- **A possible correspondence with the author's note** (suggested by Kepler; read by me in the note itself, pages 3 and 4).
  - **How the list is introduced.** The author introduces his numbered list as "a rough timeline Claude provided after a thorough search" (page 3).
  - **Item 5** (page 3) begins: "10/20/26: definitively switch to Λ aka Σ_{n≤X} Λ(n)·(X/n − 1)₊ − X log X + (1 + γ)·X; Guinand-Weil had the sign, variance test function trick to make things look trace-formula-like …"
  - **Item 6** (page 4) reads: "10/8/26: W(𝟙_(0,1] + (∼X^η)·𝟙_(0,1/X]) ≥ 0 gives > 1 − η."
  - **What matches exactly.** Item 5's expression is `Formalism.Gz` (`StatementOC.lean`, lines 11-13), term for term: the weight (X/n − 1), the main term X log X, and (1 + γ)X. The positive part in his (X/n − 1)₊ changes nothing, because the library's sum runs over n ≤ ⌊x⌋, where x/n − 1 ≥ 0 already.
  - **What is only resemblance.** Item 6 reads like a positivity statement, W(…) ≥ 0, giving a zero-free region beyond 1 − η. That is the shape of `FormBAt`, but we have not matched its symbols to anything in the library.
  - **What we have not traced.** "Guinand-Weil" in item 5 points at the explicit formula as the source of the sign. We have not found where, or whether, the library uses an explicit formula.
- **Why windows suffice.** A classical Landau argument needs the bound only along a sequence of long enough intervals, not everywhere. The library's statement of `FormBAt` makes that explicit: [Y, Y^la] for some la > 1, arbitrarily late. If this reading is right, it is the formal reason the proof never needs a bound for all x.
- **`Level.cyc ψ` and the weights.** The sum in `Gm` runs over all non-trivial characters in the group generated by ψ, with small weights (3·o + 1)⁻¹. That is the shape of a positivity device, as in the classical 3 + 4cos θ + cos 2θ ≥ 0 trick, generalised to a cyclic group of characters. Unchecked; a number theorist will see at once whether that is what it is.
